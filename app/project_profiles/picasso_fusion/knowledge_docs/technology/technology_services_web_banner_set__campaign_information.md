## Campaign Information

When conducting the Web Banner Set brief for a Technology client, the **Campaign Information** section covers the following key information.

Ask the client: What is being promoted? Provide the product, service, feature, offer, event, or campaign details.

Ask the client: Who is the target audience? Examples: Existing customers, New visitors, Small businesses, Enterprise buyers, Students, Homeowners, Healthcare professionals. The client may select one or more from: "Existing Customers", "New Visitors", "Small Businesses", "Enterprise Buyers", "Students", among others.
