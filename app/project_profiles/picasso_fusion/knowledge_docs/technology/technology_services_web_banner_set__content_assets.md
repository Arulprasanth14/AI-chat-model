## Content & Assets

When conducting the Web Banner Set brief for a Technology client, the **Content & Assets** section covers the following key information.

Ask the client: What copy should appear on the banners? Headline, supporting text, offer details, and CTA copy.

Ask the client: Do you have images, product screenshots, or visuals to use? The available choices include: "Yes", "No".

Optionally, ask the client: Upload assets. (this is not required) PNG or JPG preferred. Minimum 1200px wide. Only if you have images, product screenshots, or visuals.

In this section, 2 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
