## Production Requirements

When conducting the Product One-Pager brief for a Technology client, the **Production Requirements** section covers the following key information.

Ask the client: What size should the one-pager be? The available choices include: "A4", "US Letter", "A5", "Custom".

Ask the client: Single-sided or double-sided? A sell sheet is often double-sided, so this is worth asking. The available choices include: "Single-Sided", "Double-Sided".

Optionally, ask the client: Any technical or print-specific requirements? (this is not required) Leave blank if unsure — we'll use standard print specifications.

In this section, 2 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
