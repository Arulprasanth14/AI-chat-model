## Company Page Only (Conditional)

When conducting the LinkedIn Banner brief for a Technology client, the **Company Page Only (Conditional)** section covers the following key information.

Optionally, ask the client: What products, services, or capabilities should be highlighted? (this is not required) List the most important offerings to showcase. Only ask this if the banner is for a Company LinkedIn page (LB2 = Company LinkedIn Banner).

All questions in this section are optional. Gather this information only when the client has relevant context to share.
