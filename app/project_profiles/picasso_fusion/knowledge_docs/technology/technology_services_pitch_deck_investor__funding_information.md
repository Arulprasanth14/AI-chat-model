## Funding Information

When conducting the Pitch Deck — Investor brief for a Technology client, the **Funding Information** section covers the following key information.

Ask the client: Are you currently raising capital? The available choices include: "Yes", "No".

Optionally, ask the client: If yes, how much funding are you seeking? (this is not required) Note: Only if you are currently raising capital.

Optionally, ask the client: How will the funds be used? (this is not required) Examples: Product development, Hiring, Marketing, Operations, Expansion. Only if you are currently raising capital. The client may select one or more from: "Product Development", "Hiring", "Marketing", "Operations", "Expansion".

In this section, 1 question(s) are required and 2 are optional — follow up on optional items only when contextually appropriate.
