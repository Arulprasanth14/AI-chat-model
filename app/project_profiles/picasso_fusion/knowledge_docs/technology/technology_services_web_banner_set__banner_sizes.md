## Banner Sizes

When conducting the Web Banner Set brief for a Technology client, the **Banner Sizes** section covers the following key information.

Ask the client: What banner sizes are required? This is a 3-size package by default — confirm the standard set works, or request custom sizes. The available choices include: "Standard Display Ad Sizes", "Social Display Sizes", "Custom Sizes".

Optionally, ask the client: Please provide the exact pixel dimensions. (this is not required) Note: Only if you selected Custom Sizes above.

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
