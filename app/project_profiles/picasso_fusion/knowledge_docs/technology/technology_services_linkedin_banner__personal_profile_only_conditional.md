## Personal Profile Only (Conditional)

When conducting the LinkedIn Banner brief for a Technology client, the **Personal Profile Only (Conditional)** section covers the following key information.

Optionally, ask the client: What do you want to be known for professionally? (this is not required) Examples: Fractional CMO, SaaS Founder, Leadership Coach, Real Estate Advisor. Only ask this if the banner is for a Personal LinkedIn profile (LB2 = Personal LinkedIn Banner).

All questions in this section are optional. Gather this information only when the client has relevant context to share.
