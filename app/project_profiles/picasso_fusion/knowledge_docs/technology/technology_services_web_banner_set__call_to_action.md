## Call to Action

When conducting the Web Banner Set brief for a Technology client, the **Call to Action** section covers the following key information.

Ask the client: What action should users take after clicking the banner? Examples: Shop Now, Learn More, Book a Demo, Register, Download, Get Started. The available choices include: "Shop Now", "Learn More", "Book a Demo", "Register", "Download", "Get Started".

Ask the client: What is the destination URL?

Ask the client: Will UTM tracking be required? The available choices include: "Yes", "No".

Optionally, ask the client: Provide UTM parameters or confirm AI-generated UTMs. (this is not required) Note: Only if you said yes above.

In this section, 3 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
