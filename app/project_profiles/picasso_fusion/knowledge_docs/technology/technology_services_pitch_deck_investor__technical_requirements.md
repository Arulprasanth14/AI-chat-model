## Technical Requirements

When conducting the Pitch Deck — Investor brief for a Technology client, the **Technical Requirements** section covers the following key information.

Ask the client: What format do you need delivered? The available choices include: "PowerPoint (.pptx)", "Google Slides", "Keynote", "PDF", "Multiple Formats".

Ask the client: Will this presentation be presented live or shared for reading? This is extremely important because decks designed for live presentation are very different from decks designed to be read independently. The available choices include: "Presented Live", "Sent as a Standalone Deck", "Both".

Optionally, ask the client: Any technical, accessibility, or presentation-specific requirements? (this is not required) Leave blank if unsure.

In this section, 2 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
