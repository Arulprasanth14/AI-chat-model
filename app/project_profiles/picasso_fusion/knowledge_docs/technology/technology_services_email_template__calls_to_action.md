## Calls to Action

When conducting the Email Template brief for a Technology client, the **Calls to Action** section covers the following key information.

Ask the client: Will this template include call-to-action buttons? The available choices include: "Yes", "No".

Optionally, ask the client: What CTA buttons should be available in the template? (this is not required) Note: Only if you said yes above. The client may select one or more from: "Learn More", "Shop Now", "Register", "Book a Demo", "Contact Us".

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
