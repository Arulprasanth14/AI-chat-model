## Banner Purpose

When conducting the Web Banner Set brief for a Technology client, the **Banner Purpose** section covers the following key information.

Ask the client: What is the primary goal of these web banners? Examples: Drive sales, Promote a product launch, Generate leads, Increase sign-ups, Promote an event, Drive traffic to a landing page. The client may select one or more from: "Drive Sales", "Promote a Product Launch", "Generate Leads", "Increase Sign-Ups", "Promote an Event", among others.

Ask the client: Where will these banners appear? This is more useful than asking about homepage hero vs sidebar first. The client may select one or more from: "Website Homepage", "Website Internal Pages", "Blog/Sidebar", "Landing Page", "Display Advertising", among others.
