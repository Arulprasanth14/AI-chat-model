## Technical Requirements

When conducting the Web Banner Set brief for a Technology client, the **Technical Requirements** section covers the following key information.

Ask the client: Will these banners be static or animated? This is a critical question currently missing. The available choices include: "Static JPG/PNG", "Animated GIF", "HTML5 Banner".

Optionally, ask the client: Any platform-specific requirements? (this is not required) Examples: Google Display Network, Programmatic Ads, Internal Website. The client may select one or more from: "Google Display Network", "Programmatic Ads", "Internal Website".

Optionally, ask the client: Any technical requirements? (this is not required) Leave blank if unsure.

In this section, 1 question(s) are required and 2 are optional — follow up on optional items only when contextually appropriate.
