## Delivery Requirements

When conducting the Sales Deck — Presentation brief for a Technology client, the **Delivery Requirements** section covers the following key information.

Ask the client: Will this presentation be presented live or shared as a standalone deck? This is a critical question because live presentations use less text, while standalone decks require more context. The available choices include: "Presented Live", "Shared for Reading", "Both".

Ask the client: What format would you like delivered? The available choices include: "PowerPoint (.pptx)", "Google Slides", "Keynote", "PDF", "Multiple Formats".

Optionally, ask the client: Any technical or presentation-specific requirements? (this is not required) Leave blank if unsure.

In this section, 2 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
