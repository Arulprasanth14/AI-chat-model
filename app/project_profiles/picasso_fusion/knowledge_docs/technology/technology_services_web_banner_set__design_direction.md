## Design Direction

When conducting the Web Banner Set brief for a Technology client, the **Design Direction** section covers the following key information.

Ask the client: Any reference banners or inspiration? Share examples, competitors, or campaigns you admire. The available choices include: "Yes", "No".

Optionally, ask the client: Upload references, up to 3. (this is not required) Note: Only if you said yes to reference banners above.

Ask the client: Describe the visual style you'd like. Examples: Modern SaaS, Premium, Minimal, Product-focused, Corporate, Luxury, Bold promotional. The available choices include: "Modern SaaS", "Premium", "Minimal", "Product-Focused", "Corporate", "Luxury", or other options.

In this section, 2 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
