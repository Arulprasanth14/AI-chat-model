## Design Direction

When conducting the Pitch Deck — Investor brief for a Technology client, the **Design Direction** section covers the following key information.

Ask the client: Any investor decks or presentation designs you admire? Examples: Sequoia-style, YC-style, Modern SaaS, Corporate, Premium, Minimal. The available choices include: "Yes", "No".

Optionally, ask the client: Upload reference presentations, up to 3. (this is not required) Note: Only if you said yes to reference decks above.

Ask the client: Describe the presentation style you'd like. Examples: Investor-grade, Premium, Corporate, Minimal, Technology-focused, Bold startup, Data-driven. The available choices include: "Investor-Grade", "Premium", "Corporate", "Minimal", "Technology-Focused", "Bold Startup", or other options.

In this section, 2 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
