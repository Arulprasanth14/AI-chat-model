## Design Direction

When conducting the Product One-Pager brief for a Technology client, the **Design Direction** section covers the following key information.

Ask the client: Any reference designs or inspiration? Competitors, favourite brands, previous sell sheets, or examples you admire. The available choices include: "Yes", "No".

Optionally, ask the client: Upload reference designs, up to 3. (this is not required) Note: Only if you said yes to reference designs above.

Ask the client: Describe the visual style you'd like. Examples: Premium, corporate, modern, bold, minimal, technical, luxury, retail-focused. The available choices include: "Premium", "Corporate", "Modern", "Bold", "Minimal", "Technical", or other options.

In this section, 2 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
