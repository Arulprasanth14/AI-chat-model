## Technical Requirements

When conducting the Email Template brief for a Technology client, the **Technical Requirements** section covers the following key information.

Ask the client: Do you require a fully coded HTML email or a design-only template? This is a critical question that's currently missing. The available choices include: "Fully Coded HTML Email", "Design Only", "Not Sure".
