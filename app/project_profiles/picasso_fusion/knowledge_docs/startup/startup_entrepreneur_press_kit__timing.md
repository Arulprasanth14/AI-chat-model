## Timing

When conducting the Press Kit brief for a Startup client, the **Timing** section covers the following key information.

Ask the client: Is there an announcement date or embargo? Important for media scheduling. The available choices include: "Immediate Release", "Scheduled Release Date", "Embargoed Announcement".

Optionally, ask the client: Provide announcement date and time. (this is not required) Note: Only if you selected Scheduled Release Date or Embargoed Announcement above.

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
