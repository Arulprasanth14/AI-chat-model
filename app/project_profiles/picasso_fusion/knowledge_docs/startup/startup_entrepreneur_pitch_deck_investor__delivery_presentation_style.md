## Delivery & Presentation Style

When conducting the Pitch Deck — Investor brief for a Startup client, the **Delivery & Presentation Style** section covers the following key information.

Ask the client: Will this deck be presented live or sent to investors for review? This affects slide density and storytelling style. The available choices include: "Live Presentation", "Send-Ahead Deck", "Both".

Ask the client: Do you have any reference pitch decks or presentation styles? Competitor decks, successful startup decks, or visual styles you admire. The available choices include: "Yes", "No".

Optionally, ask the client: Upload reference decks, up to 3. (this is not required) Note: Only if you said yes to reference decks above.

Ask the client: Describe the presentation style you'd like. The available choices include: "Investor-Grade", "Minimal", "Premium", "SaaS", "Data-Driven", "Bold Startup", or other options.

In this section, 3 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
