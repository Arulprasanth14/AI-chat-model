## Print & Production

When conducting the Business Card brief for a Startup client, the **Print & Production** section covers the following key information.

Optionally, ask the client: Any print-specific requirements? (this is not required) Leave blank if unsure. The client may select one or more from: "Matte Finish", "Soft-Touch Lamination", "Spot UV", "Foil Stamping", "Embossing", among others.

Ask the client: Will multiple employees use this design template? This determines whether the designer should create a reusable business card system. The available choices include: "Yes", "No".

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
