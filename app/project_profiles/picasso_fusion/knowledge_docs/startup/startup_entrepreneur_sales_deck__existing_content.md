## Existing Content

When conducting the Sales Deck — Presentation brief for a Startup client, the **Existing Content** section covers the following key information.

Ask the client: Do you already have content or an existing sales deck? The available choices include: "Complete Deck Available", "Partial Content Available", "Need Help Structuring Content", "Need Help Creating Content".

Optionally, ask the client: Upload your existing deck, sales materials, or supporting documents. (this is not required) Accepted formats: PPTX, PDF, DOCX, Google Slides export. Only if you have existing content.

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
