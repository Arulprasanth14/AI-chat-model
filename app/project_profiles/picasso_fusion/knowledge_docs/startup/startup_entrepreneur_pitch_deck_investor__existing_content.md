## Existing Content

When conducting the Pitch Deck — Investor brief for a Startup client, the **Existing Content** section covers the following key information.

Ask the client: Do you already have content, notes, or an existing deck? The available choices include: "Yes, complete deck", "Partial content available", "Need help structuring content", "Need help creating content".

Optionally, ask the client: Upload existing deck, content, or supporting documents. (this is not required) Accepted formats: PPTX, PDF, DOCX, Google Slides export. Only if you have existing content.

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
