## Platform & Format

When conducting the Proposal Template brief for a Startup client, the **Platform & Format** section covers the following key information.

Ask the client: Which platform will the template be used in? This question is critical and currently missing. The available choices include: "PowerPoint", "Google Slides", "Canva", "Word", "InDesign", "Figma", or other options.

Ask the client: Output formats required? The available choices include: "Editable Source File", "PDF", "PowerPoint", "Google Slides", "Canva Template", "Multiple Formats".
