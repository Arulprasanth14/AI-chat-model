## Media Coverage & Distribution

When conducting the Press Kit brief for a Startup client, the **Media Coverage & Distribution** section covers the following key information.

Ask the client: Has the company received any notable media coverage, awards, or recognition? The available choices include: "Yes", "No".

Optionally, ask the client: Provide links, publications, awards, or recognition details. (this is not required) Note: Only if you said yes above.

Ask the client: Will media assets need to be downloadable separately? This affects how the press kit is structured. The available choices include: "Yes", "No".

In this section, 2 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
