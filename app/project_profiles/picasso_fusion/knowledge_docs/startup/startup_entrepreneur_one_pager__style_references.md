## Style & References

When conducting the One-Pager — Company Overview brief for a Startup client, the **Style & References** section covers the following key information.

Ask the client: Any reference one-pagers or company profiles you'd like us to reference? Share examples you admire or competitors you like. The available choices include: "Yes", "No".

Optionally, ask the client: Upload reference documents, up to 3. (this is not required) Note: Only if you said yes to reference one-pagers above.

Ask the client: Describe the visual style you'd like. The available choices include: "Startup", "Investor-Grade", "Modern SaaS", "Corporate", "Premium", "Minimal", or other options.

Optionally, ask the client: Any technical requirements? (this is not required) Leave blank if unsure. The client may select one or more from: "A4", "US Letter", "Interactive PDF", "Print-Ready PDF", "Editable Source File".

In this section, 2 question(s) are required and 2 are optional — follow up on optional items only when contextually appropriate.
