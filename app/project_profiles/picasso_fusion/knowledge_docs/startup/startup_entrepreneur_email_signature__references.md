## References

When conducting the Email Signature brief for a Startup client, the **References** section covers the following key information.

Ask the client: Any reference signatures or inspiration? The available choices include: "Yes", "No".

Optionally, ask the client: Upload reference signatures, up to 3. (this is not required) Note: Only if you said yes to reference signatures above.
