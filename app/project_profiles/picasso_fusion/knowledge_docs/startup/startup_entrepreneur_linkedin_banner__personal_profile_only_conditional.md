## Personal Profile Only (Conditional)

When conducting the LinkedIn Banner brief for a Startup client, the **Personal Profile Only (Conditional)** section covers the following key information.

Optionally, ask the client: What headline or positioning statement should visitors immediately understand? (this is not required) Keep it concise and memorable. Only ask this if the banner is for a Personal Profile (LB1 = Personal Profile).

Optionally, ask the client: What services, expertise, or specialties should be highlighted? (this is not required) Examples: SaaS Growth, Real Estate, Product Design, Marketing Strategy, AI Consulting. Only ask this if the banner is for a Personal Profile (LB1 = Personal Profile).

All questions in this section are optional. Gather this information only when the client has relevant context to share.
