## Platform & Technical Specs

When conducting the Presentation Template — Reusable Master brief for a Startup client, the **Platform & Technical Specs** section covers the following key information.

Ask the client: Which presentation platform will be used? This is one of the most important questions and is currently missing. The available choices include: "PowerPoint", "Google Slides", "Keynote", "Canva", "Multiple Platforms".

Ask the client: Should the template include editable charts, tables, and infographics? The available choices include: "Yes", "No".

Ask the client: What level of editability is required? The available choices include: "Fully Editable", "Locked Brand Elements", "Beginner-Friendly", "Advanced User Template".
