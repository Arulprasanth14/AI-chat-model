## Style & References

When conducting the Presentation Template — Reusable Master brief for a Startup client, the **Style & References** section covers the following key information.

Ask the client: Preferred presentation style? The available choices include: "Startup", "Investor-Grade", "Modern SaaS", "Corporate", "Premium", "Minimal", or other options.

Ask the client: Any reference presentations or templates? Share examples you like or currently use. The available choices include: "Yes", "No".

Optionally, ask the client: Upload reference presentations, up to 3. (this is not required) Note: Only if you said yes to reference presentations above.

In this section, 2 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
