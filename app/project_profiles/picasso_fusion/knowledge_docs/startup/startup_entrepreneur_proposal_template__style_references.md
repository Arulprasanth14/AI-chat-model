## Style & References

When conducting the Proposal Template brief for a Startup client, the **Style & References** section covers the following key information.

Ask the client: Any reference proposals or inspiration? Share examples you admire or currently use. The available choices include: "Yes", "No".

Optionally, ask the client: Upload proposal examples, up to 3. (this is not required) Note: Only if you said yes to reference proposals above.

Ask the client: Describe the desired proposal style. The available choices include: "Corporate", "Premium", "Startup", "Minimal", "Enterprise", "Consulting", or other options.

Optionally, ask the client: Any technical requirements? (this is not required) Leave blank if unsure. The client may select one or more from: "A4 Portrait", "US Letter", "Interactive PDF", "Digital Signing Section", "Proposal Cover Variations", among others.

In this section, 2 question(s) are required and 2 are optional — follow up on optional items only when contextually appropriate.
