## Branding & Assets

When conducting the Proposal Template brief for a Startup client, the **Branding & Assets** section covers the following key information.

Ask the client: Do you have branding assets? Templates should align with brand standards. The available choices include: "Full Brand Guidelines", "Logo Only", "Existing Proposal", "Website Branding", "No Brand Assets Yet".

Optionally, ask the client: Upload logo, brand guide, fonts, and visual assets. (this is not required) Editable assets preferred. Only if you have branding assets.

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
