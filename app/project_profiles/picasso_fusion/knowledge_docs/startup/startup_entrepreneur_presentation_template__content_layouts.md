## Content & Layouts

When conducting the Presentation Template — Reusable Master brief for a Startup client, the **Content & Layouts** section covers the following key information.

Ask the client: Which slide layouts are required? Select all layouts that should be included. The client may select one or more from: "Cover Slide", "Section Divider", "Agenda", "Team Introduction", "Problem / Opportunity", among others.

Ask the client: How many template layouts are required? The available choices include: "10 Slides", "15 Slides", "20 Slides", "25+ Slides".
