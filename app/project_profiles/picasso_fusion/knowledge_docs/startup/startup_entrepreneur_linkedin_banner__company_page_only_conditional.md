## Company Page Only (Conditional)

When conducting the LinkedIn Banner brief for a Startup client, the **Company Page Only (Conditional)** section covers the following key information.

Optionally, ask the client: What key company message should visitors immediately understand? (this is not required) Focus on your value proposition. Only ask this if the banner is for a Company Page (LB1 = Company Page).

Optionally, ask the client: What products, services, or capabilities should be highlighted? (this is not required) Note: Only ask this if the banner is for a Company Page (LB1 = Company Page).

All questions in this section are optional. Gather this information only when the client has relevant context to share.
