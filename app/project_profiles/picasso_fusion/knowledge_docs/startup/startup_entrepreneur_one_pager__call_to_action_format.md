## Call to Action & Format

When conducting the One-Pager — Company Overview brief for a Startup client, the **Call to Action & Format** section covers the following key information.

Ask the client: What is the primary call to action? Every one-pager should encourage a clear next step. The available choices include: "Book a Meeting", "Request a Demo", "Contact Us", "Invest", "Visit Website", "Partner With Us".

Optionally, ask the client: Custom CTA text. (this is not required) Note: Only if you selected Other above.

Ask the client: Will this one-pager be printed, shared digitally, or both? This affects layout, readability, and interactivity. The available choices include: "Print", "Digital PDF", "Both".

In this section, 2 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
