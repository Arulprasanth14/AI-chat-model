## Proposal Overview

When conducting the Proposal Template brief for a Startup client, the **Proposal Overview** section covers the following key information.

Ask the client: What is this proposal template for? One proposal template = one repeatable sales process. The available choices include: "Service Proposal", "Agency Proposal", "Consulting Proposal", "Software / SaaS Proposal", "Partnership Proposal", "Investment Proposal", or other options.

Ask the client: What services, products, or solutions will typically be proposed? Understanding the offering helps structure the template correctly.

Ask the client: Who is the target audience? Proposal content and tone should match the decision-maker. The client may select one or more from: "Small Business Owners", "Enterprise Buyers", "Startups", "Corporate Procurement Teams", "Investors", among others.

Ask the client: Who will be using this template internally? Template complexity should match the user. The client may select one or more from: "Founder", "Sales Team", "Business Development Team", "Account Managers", "Entire Company".
