## Content & Pricing

When conducting the Proposal Template brief for a Startup client, the **Content & Pricing** section covers the following key information.

Ask the client: Which sections should the template include? Select all required sections. Multi-select. The client may select one or more from: "Cover Page", "Executive Summary", "About Us", "Problem Statement", "Proposed Solution", among others.

Ask the client: What pricing structure should the template support? Proposal layouts vary significantly based on pricing model. The available choices include: "Fixed Price", "Retainer", "Tiered Packages", "Hourly", "Subscription", "Custom Pricing", or other options.

Ask the client: Should pricing tables be editable? This is one of the most important template questions. The available choices include: "Yes", "No".
