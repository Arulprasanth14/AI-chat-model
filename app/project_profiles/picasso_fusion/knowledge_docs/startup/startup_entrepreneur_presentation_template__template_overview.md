## Template Overview

When conducting the Presentation Template — Reusable Master brief for a Startup client, the **Template Overview** section covers the following key information.

Ask the client: What will this presentation template be used for? Understanding the use case helps determine the required slide layouts. The available choices include: "Pitch Decks", "Sales Presentations", "Investor Updates", "Board Meetings", "Company Reports", "Product Presentations", or other options.

Ask the client: Who will be using this template? Template complexity should match the user's skill level. The client may select one or more from: "Founder", "Sales Team", "Marketing Team", "Executive Team", "Entire Company".
