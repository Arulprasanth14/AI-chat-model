## Call to Action

When conducting the Proposal Template brief for a Startup client, the **Call to Action** section covers the following key information.

Ask the client: What call to action should appear at the end of the proposal? Every proposal should guide the prospect toward acceptance. The available choices include: "Approve Proposal", "Schedule a Meeting", "Sign Agreement", "Contact Us".

Optionally, ask the client: Custom CTA text. (this is not required) Note: Only if you selected Other above.

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
