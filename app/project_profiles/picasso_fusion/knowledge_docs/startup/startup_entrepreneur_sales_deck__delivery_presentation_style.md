## Delivery & Presentation Style

When conducting the Sales Deck — Presentation brief for a Startup client, the **Delivery & Presentation Style** section covers the following key information.

Ask the client: How will this deck be used? This is one of the most important questions because a live deck and a send-ahead deck require different content density. The available choices include: "Live Sales Presentation", "Send as PDF", "Both".

Ask the client: Any sales decks or presentation styles you'd like us to reference? Competitor decks, industry examples, or presentations you admire. The available choices include: "Yes", "No".

Optionally, ask the client: Upload reference decks, up to 3. (this is not required) Note: Only if you said yes to reference decks above.

Ask the client: Describe the presentation style you'd like. The available choices include: "Modern SaaS", "Corporate", "Premium", "Startup", "Data-Driven", "Minimal", or other options.

In this section, 3 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
