## Design Direction

When conducting the LinkedIn Banner brief for a Startup client, the **Design Direction** section covers the following key information.

Ask the client: Any reference banners or inspiration? The available choices include: "Yes", "No".

Optionally, ask the client: Upload reference banners, up to 3. (this is not required) Note: Only if you said yes to reference banners above.

Ask the client: Preferred design style? Choose a visual direction. The available choices include: "Corporate", "Premium", "Modern", "Minimal", "Startup", "Technology", or other options.

In this section, 2 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
