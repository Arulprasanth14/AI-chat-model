## Brand Elements & Technical Requirements

When conducting the Presentation Template — Reusable Master brief for a Startup client, the **Brand Elements & Technical Requirements** section covers the following key information.

Optionally, ask the client: Are there any mandatory brand elements that must appear throughout the template? (this is not required) The client may select one or more from: "Logo Placement", "Footer", "Page Numbers", "Brand Shapes", "Brand Icons", among others.

Optionally, ask the client: Any technical requirements? (this is not required) The client may select one or more from: "16:9 Widescreen", "4:3 Format", "Light Theme", "Dark Theme", "Master Slides Required", among others.

All questions in this section are optional. Gather this information only when the client has relevant context to share.
