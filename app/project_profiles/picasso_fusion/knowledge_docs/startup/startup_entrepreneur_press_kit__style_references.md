## Style & References

When conducting the Press Kit brief for a Startup client, the **Style & References** section covers the following key information.

Ask the client: Any reference press kits or media kits you'd like us to reference? Share examples you admire. The available choices include: "Yes", "No".

Optionally, ask the client: Upload reference press kits, up to 3. (this is not required) Note: Only if you said yes to reference press kits above.

Ask the client: Describe the visual style you'd like. The available choices include: "Startup", "Corporate", "Investor-Grade", "Minimal", "Premium", "Technology-Focused".

Optionally, ask the client: Any technical requirements? (this is not required) Leave blank if unsure. The client may select one or more from: "PDF Only", "Print-Ready", "Interactive PDF", "Press Download Folder", "Editable Source Files".

In this section, 2 question(s) are required and 2 are optional — follow up on optional items only when contextually appropriate.
