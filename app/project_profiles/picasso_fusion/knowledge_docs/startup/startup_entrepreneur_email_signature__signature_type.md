## Signature Type

When conducting the Email Signature brief for a Startup client, the **Signature Type** section covers the following key information.

Ask the client: Is this email signature for an individual or a company-wide template? This determines how flexible the signature needs to be. The available choices include: "Individual Signature", "Team Template", "Company-Wide Template".
