## Branding & Assets

When conducting the Presentation Template — Reusable Master brief for a Startup client, the **Branding & Assets** section covers the following key information.

Ask the client: What branding assets are available? Consistent branding creates professional presentations. The available choices include: "Full Brand Guidelines", "Logo Only", "Existing Presentation", "Website Branding", "No Branding Yet".

Optionally, ask the client: Upload logo, fonts, brand guidelines, and visual assets. (this is not required) Accepted formats: SVG, PNG, PDF, PPTX. Only if you have branding assets.

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
