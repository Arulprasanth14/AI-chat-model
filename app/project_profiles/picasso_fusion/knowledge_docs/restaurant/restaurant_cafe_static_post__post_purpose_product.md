## Post Purpose & Product

When conducting the Static Post brief for a Restaurant client, the **Post Purpose & Product** section covers the following key information.

Ask the client: What are we creating today? Select the purpose of this post. The available choices include: "Featured Dish", "New Menu Item", "Seasonal Special", "Chef's Recommendation", "Combo / Meal Offer", "Happy Hour", or other options.

Ask the client: What are we promoting? Provide the key details: Dish/Menu/Event Name, Category, Price (Optional), Key Ingredients/Highlights.

Ask the client: What's the ONE message customers should remember? Describe the biggest reason someone should visit or order. Example: "Freshly baked every morning.", "Limited-time mango dessert.", "Weekend brunch you can't miss.".
