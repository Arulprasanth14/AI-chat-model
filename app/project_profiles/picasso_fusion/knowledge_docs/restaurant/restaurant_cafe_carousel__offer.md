## Offer

When conducting the Carousel brief for a Restaurant client, the **Offer** section covers the following key information.

Ask the client: Are you running an offer? The available choices include: "No Offer", "Percentage Discount", "Combo Offer", "Happy Hour", "Buy One Get One", "Free Dessert", or other options.

Optionally, ask the client: Provide the offer details, start & end date, and terms & conditions. (this is not required) Note: Only if you are running an offer.

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
