## Print Item & Message

When conducting the Print Design brief for a Restaurant client, the **Print Item & Message** section covers the following key information.

Ask the client: What are we creating today? Select the print item. The available choices include: "Restaurant Menu", "Menu Insert / Seasonal Menu", "Table Tent", "Table Mat", "Poster", "Flyer", or other options.

Ask the client: What are we promoting? Provide the key details: Dish/Menu/Event Name, Category, Price (Optional), Key Ingredients/Highlights.

Ask the client: What's the ONE message customers should remember? Describe the biggest takeaway after seeing this print piece. Example: "Try our new summer menu.", "Weekend brunch is now available.", "Book your table for Valentine's Dinner.".
