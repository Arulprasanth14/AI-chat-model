## Style & References

When conducting the Static Post brief for a Restaurant client, the **Style & References** section covers the following key information.

Ask the client: What visual style should this post have? Choose up to 3. The client may select one or more from: "Premium", "Luxury", "Rustic", "Modern", "Minimal", among others.

Optionally, ask the client: Do you have any inspiration? (this is not required) Share posts or brands you like. The client may select one or more from: "Instagram Link", "Pinterest Link", "Website Link", "Upload Reference Images", "Skip".

Optionally, ask the client: Provide the reference link(s), or note that you're uploading images. (this is not required) Note: Only if you selected a reference option above (not Skip).

In this section, 1 question(s) are required and 2 are optional — follow up on optional items only when contextually appropriate.
