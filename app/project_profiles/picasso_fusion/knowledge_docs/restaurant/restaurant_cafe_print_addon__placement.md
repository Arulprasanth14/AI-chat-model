## Placement

When conducting the Print Design brief for a Restaurant client, the **Placement** section covers the following key information.

Ask the client: Where will this print piece be displayed? The client may select one or more from: "Inside Restaurant", "Storefront / Entrance", "Outdoor", "Tabletop", "Checkout Counter", among others.
