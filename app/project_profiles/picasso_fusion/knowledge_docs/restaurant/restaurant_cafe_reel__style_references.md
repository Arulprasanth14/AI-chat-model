## Style & References

When conducting the Reel brief for a Restaurant client, the **Style & References** section covers the following key information.

Optionally, ask the client: Do you have any inspiration? (this is not required) Share reels or videos you like. The client may select one or more from: "Instagram Link", "TikTok Link", "YouTube Link", "Upload Reference Videos", "Skip".

Optionally, ask the client: Provide the reference link(s). (this is not required) Note: Only if you selected Instagram Link, TikTok Link, or YouTube Link above.

Optionally, ask the client: Upload reference videos. (this is not required) Note: Only if you selected "Upload Reference Videos" above.

All questions in this section are optional. Gather this information only when the client has relevant context to share.
