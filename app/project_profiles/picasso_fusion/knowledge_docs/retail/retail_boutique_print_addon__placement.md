## Placement

When conducting the Print Design brief for a Retail client, the **Placement** section covers the following key information.

Ask the client: Where will this print piece be displayed? The client may select one or more from: "Store Window", "Inside Store", "Checkout Counter", "Shopping Mall", "Exhibition / Trade Show", among others.
