## Placement & Format

When conducting the Digital Asset brief for a Retail client, the **Placement & Format** section covers the following key information.

Ask the client: Where will this asset be used? The client may select one or more from: "Website", "Email Campaign", "Google Ads", "Meta Ads", "Instagram", among others.

Ask the client: What size or format do you need? The available choices include: "Standard Platform Size", "Multiple Platform Sizes", "Custom Dimensions".

Optionally, ask the client: Provide the width × height in pixels. (this is not required) Note: Only if you selected Custom Dimensions above.

In this section, 2 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
