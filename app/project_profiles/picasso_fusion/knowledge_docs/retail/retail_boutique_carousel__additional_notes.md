## Additional Notes

When conducting the Carousel brief for a Retail client, the **Additional Notes** section covers the following key information.

Optionally, ask the client: Is there anything you'd like us to avoid? (this is not required) Mention any colours, imagery, wording, competitor references, or visual directions you'd prefer not to use.

All questions in this section are optional. Gather this information only when the client has relevant context to share.
