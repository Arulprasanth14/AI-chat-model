## Print Item & Message

When conducting the Print Design brief for a Retail client, the **Print Item & Message** section covers the following key information.

Ask the client: What are we creating today? Select the print item. The available choices include: "Store Poster", "Flyer", "Brochure", "Roll-up Standee", "Window Graphic", "Retail Banner", or other options.

Ask the client: What are we promoting? Provide the key details: Product/Collection/Campaign Name, Category, Price (Optional), Key Features/Benefits.

Ask the client: What's the ONE message customers should remember? Describe the biggest reason someone should notice this print piece. Example: "Visit us for our biggest sale of the season.", "Discover our latest home décor collection.", "Exclusive offers available in-store only.".
