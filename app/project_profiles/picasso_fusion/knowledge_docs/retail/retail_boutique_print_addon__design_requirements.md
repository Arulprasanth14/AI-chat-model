## Design Requirements

When conducting the Print Design brief for a Retail client, the **Design Requirements** section covers the following key information.

Optionally, ask the client: Is there anything that must appear? (this is not required) Select all that apply. The client may select one or more from: "Product Name", "Collection Name", "Price", "Discount", "Brand Logo", among others.

All questions in this section are optional. Gather this information only when the client has relevant context to share.
