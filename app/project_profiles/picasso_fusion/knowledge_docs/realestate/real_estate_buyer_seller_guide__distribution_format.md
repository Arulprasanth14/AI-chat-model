## Distribution Format

When conducting the Buyer / Seller Guide brief for a Real Estate client, the **Distribution Format** section covers the following key information.

Ask the client: How will this guide be distributed? This is much more useful to ask than a generic "what output format is required" question. The available choices include: "Printed Guide", "Downloadable PDF", "Lead Magnet", "Email Attachment", "LinkedIn PDF Carousel", "Both Print & Digital".
