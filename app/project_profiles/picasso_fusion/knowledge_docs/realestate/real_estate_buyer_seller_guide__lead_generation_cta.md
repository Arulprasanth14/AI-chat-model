## Lead Generation & CTA

When conducting the Buyer / Seller Guide brief for a Real Estate client, the **Lead Generation & CTA** section covers the following key information.

Ask the client: What action should readers take after reading the guide? The available choices include: "Request an appraisal", "Book a consultation", "Contact an agent", "Download additional resources", "Visit the website".

Ask the client: Will a QR code be included? The available choices include: "Yes", "No".

Optionally, ask the client: What URL should the QR code link to? (this is not required) Note: Only ask this if the client said yes to including a QR code.

In this section, 2 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
