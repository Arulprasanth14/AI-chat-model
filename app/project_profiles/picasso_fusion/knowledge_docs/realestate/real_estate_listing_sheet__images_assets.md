## Images & Assets

When conducting the Real Estate Listing Sheet brief for a Real Estate client, the **Images & Assets** section covers the following key information.

Ask the client: Do you have professional property photography? Please upload the images. Minimum 300 DPI for print. High-resolution JPG preferred.

Ask the client: Do you have any additional assets to include? The client may select one or more from: "Floor plan", "Site plan", "Location map", "Agent photo", "Agency awards", among others.

Optionally, ask the client: Please upload the additional assets you selected. (this is not required) Note: Only ask this if the client selected any asset other than "None" above.

In this section, 2 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
