## Property Content

When conducting the Open Home Signboard brief for a Real Estate client, the **Property Content** section covers the following key information.

Ask the client: What property details should appear? Examples: bedrooms, bathrooms, car spaces, land size, price guide, auction date.

Ask the client: What key message should the signboard communicate? Examples: "Open Home Today", "Auction This Saturday", "New Listing", "Luxury Waterfront Living", "Contact Agent".
