## Testimonial Content

When conducting the Testimonial Set brief for a Real Estate client, the **Testimonial Content** section covers the following key information.

Ask the client: What testimonial should be featured? Please provide the final, approved testimonial text.

Ask the client: What result, outcome, or success story should be highlighted? The client may select one or more from: "Increased sales", "Faster growth", "Saved time", "Improved efficiency", "Successful property sale", among others.

Optionally, ask the client: Do you have any supporting metrics or proof points? (this is not required) Examples: sold in 14 days, 25% increase in revenue, 4x ROI, 100+ customers gained.

In this section, 2 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
