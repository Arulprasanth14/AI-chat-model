## Open Home Information

When conducting the Open Home Signboard brief for a Real Estate client, the **Open Home Information** section covers the following key information.

Ask the client: What property is this signboard promoting? Give the property address.

Ask the client: What type of property is it? The available choices include: "House", "Apartment", "Townhouse", "Villa", "Land", "Commercial Property".

Ask the client: What is the purpose of the signboard? The available choices include: "Open Home", "Auction", "New Listing", "Sold Property", "Directional Sign", "Custom".

Optionally, ask the client: What date and time is the open home? (this is not required) Required if promoting an inspection — only ask this if the purpose above is Open Home or Auction.

In this section, 3 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
