## Flyer / Brochure Format

When conducting the Property Flyer / Brochure brief for a Real Estate client, the **Flyer / Brochure Format** section covers the following key information.

Ask the client: What format do you need? The available choices include: "Property Flyer", "Bi-Fold Brochure", "Tri-Fold Brochure", "Multi-Page Property Brochure".

Optionally, ask the client: How many pages or panels are required? (this is not required) Required for brochure formats — only ask this if the format above is a Bi-Fold, Tri-Fold, or Multi-Page Brochure, not a single-sheet Property Flyer.

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
