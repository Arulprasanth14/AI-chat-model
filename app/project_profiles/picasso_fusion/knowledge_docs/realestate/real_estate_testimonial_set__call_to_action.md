## Call to Action

When conducting the Testimonial Set brief for a Real Estate client, the **Call to Action** section covers the following key information.

Ask the client: What action should viewers take after seeing this testimonial? The available choices include: "Contact us", "Book a consultation", "Request a demo", "Learn more", "Visit our website".

Ask the client: What is the destination URL?

Ask the client: Will UTM tracking be required? The available choices include: "Yes", "No".

Optionally, ask the client: Please provide the UTM parameters, or confirm you'd like AI-generated UTMs. (this is not required) Note: Only ask this if the client said yes to UTM tracking above.

In this section, 3 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
