## Guide Content

When conducting the Buyer / Seller Guide brief for a Real Estate client, the **Guide Content** section covers the following key information.

Ask the client: What topics or sections should be included? The client may select one or more from: "Buying process", "Selling process", "Financing", "Property preparation", "Market insights", among others.

Ask the client: Do you already have the content prepared? The available choices include: "Yes, final content ready", "Partial content available", "Need help organising content", "Need help writing content".

Optionally, ask the client: Please upload your content files. (this is not required) Accepted formats: DOCX, PDF, Google Docs export.

Ask the client: Approximately how many pages should the guide contain? The available choices include: "4 Pages", "8 Pages", "12 Pages", "16+ Pages".

In this section, 3 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
