## Thumbnail Template System

When conducting the YouTube Banner brief for a Real Estate client, the **Thumbnail Template System** section covers the following key information.

Ask the client: What types of videos will these thumbnail templates be used for? The client may select one or more from: "Tutorials", "Property Tours", "Product Reviews", "Interviews", "Podcasts", among others.

Ask the client: How many thumbnail template variations are required? The available choices include: "1 Universal Template", "3 Content Categories", "5 Content Categories", "Custom".

Ask the client: What recurring elements should appear on thumbnails? The client may select one or more from: "Presenter Photo", "Logo", "Episode Number", "Category Label", "Brand Colours", among others.
