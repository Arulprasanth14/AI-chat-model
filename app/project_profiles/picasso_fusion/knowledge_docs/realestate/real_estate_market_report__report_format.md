## Report Format

When conducting the Real Estate Market Report brief for a Real Estate client, the **Report Format** section covers the following key information.

Ask the client: What format is required? This is critical — the layout changes significantly depending on distribution. The available choices include: "Printed Report", "Digital PDF", "LinkedIn PDF Carousel", "Email Attachment", "Both Print & Digital".

Ask the client: How many pages should the report contain? The available choices include: "4 Pages", "8 Pages", "12 Pages", "Custom".
