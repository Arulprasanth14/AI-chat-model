## YouTube Banner

When conducting the YouTube Banner brief for a Real Estate client, the **YouTube Banner** section covers the following key information.

Ask the client: What key message should appear on the channel banner? Examples: channel tagline, value proposition, upload schedule, website URL, services offered.

Ask the client: What text should appear on the banner? Please provide final banner copy.
