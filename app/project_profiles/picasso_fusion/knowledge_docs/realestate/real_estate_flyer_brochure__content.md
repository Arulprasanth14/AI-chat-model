## Content

When conducting the Property Flyer / Brochure brief for a Real Estate client, the **Content** section covers the following key information.

Ask the client: What property description should appear in the flyer or brochure? Please provide final, approved copy.

Optionally, ask the client: Are there any mandatory disclosures or legal statements? (this is not required)

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
