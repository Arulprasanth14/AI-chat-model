## Core Message

When conducting the LinkedIn Banner brief for a Real Estate client, the **Core Message** section covers the following key information.

Ask the client: What is the key message this banner should communicate? One clear message works best. Examples: "Helping businesses scale with AI", "Australia's trusted property advisors", "Award-winning digital marketing agency", "Building the future of fintech".

Ask the client: What text should appear on the banner? Examples: tagline, service list, company slogan, credentials, website URL, professional title.
