## Technical Requirements

When conducting the Real Estate Market Report brief for a Real Estate client, the **Technical Requirements** section covers the following key information.

Ask the client: Will this report be printed, viewed digitally, or both? The available choices include: "Print Only", "Digital Only", "Both".

Optionally, ask the client: Any other technical or production requirements? (this is not required) Examples: interactive PDF, print-ready PDF, LinkedIn carousel format, custom page size. Leave blank if unsure.

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
