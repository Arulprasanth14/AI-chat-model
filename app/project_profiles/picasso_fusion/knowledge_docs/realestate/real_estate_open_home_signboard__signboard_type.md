## Signboard Type

When conducting the Open Home Signboard brief for a Real Estate client, the **Signboard Type** section covers the following key information.

Ask the client: What type of signboard is required? The available choices include: "A-Frame Sign", "Corflute Sign", "Directional Sign", "Open Home Pointer Sign", "Pull-Up Banner", "Fence Sign", or other options.

Ask the client: What are the dimensions? Provide printer specifications if available.
