## Agent & Contact Information

When conducting the Property Flyer / Brochure brief for a Real Estate client, the **Agent & Contact Information** section covers the following key information.

Ask the client: Which agent details should appear? Give the agent name, phone number, email address, website, and agency office.

Ask the client: What is the primary call to action? The available choices include: "Contact Agent", "Book an Inspection", "Register for Auction", "Schedule a Viewing", "Download Full Property Pack".

Ask the client: Will a QR code be included? The available choices include: "Yes", "No".

Optionally, ask the client: What URL should the QR code link to? (this is not required) Note: Only ask this if the client said yes to including a QR code. Examples: property listing page, virtual tour, booking page, agency website.

In this section, 3 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
