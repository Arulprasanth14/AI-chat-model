## Agent Information

When conducting the Open Home Signboard brief for a Real Estate client, the **Agent Information** section covers the following key information.

Ask the client: Which agent details should appear? Give the agent name, phone number, email, and website.

Ask the client: What is the primary call to action? The available choices include: "Inspect Today", "Contact Agent", "Register for Auction", "Scan for Property Details", "Book a Viewing".

Ask the client: Will a QR code be included? The available choices include: "Yes", "No".

Optionally, ask the client: What URL should the QR code link to? (this is not required) Note: Only ask this if the client said yes to including a QR code. Examples: property listing, virtual tour, agency website, inspection registration.

In this section, 3 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
