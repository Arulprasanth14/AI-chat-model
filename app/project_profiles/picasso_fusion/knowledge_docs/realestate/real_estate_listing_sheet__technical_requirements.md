## Technical Requirements

When conducting the Real Estate Listing Sheet brief for a Real Estate client, the **Technical Requirements** section covers the following key information.

Ask the client: Will this listing sheet be used for print, digital distribution, or both? This is surprisingly important — digital listing sheets often need clickable links and different layouts. The available choices include: "Print only", "Digital PDF only", "Both".

Optionally, ask the client: Any other technical or production requirements? (this is not required) Leave blank if unsure.

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
