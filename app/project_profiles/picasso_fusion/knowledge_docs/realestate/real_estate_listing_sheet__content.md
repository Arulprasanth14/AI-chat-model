## Content

When conducting the Real Estate Listing Sheet brief for a Real Estate client, the **Content** section covers the following key information.

Ask the client: What property description should appear on the listing sheet? Please provide final, approved copy.

Optionally, ask the client: Are there any disclaimers, legal notices, or compliance statements required? (this is not required)

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
