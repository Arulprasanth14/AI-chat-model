## Platform & Format

When conducting the Testimonial Set brief for a Real Estate client, the **Platform & Format** section covers the following key information.

Ask the client: Where will these testimonial creatives be used? This is much more important to ask than generic technical requirements. The client may select one or more from: "Instagram", "Facebook", "LinkedIn", "Website", "Google Display", among others.

Ask the client: Are these static graphics or video-based testimonials? The available choices include: "Static Graphics", "Motion Graphics", "Video Testimonials", "Mixed Set".
