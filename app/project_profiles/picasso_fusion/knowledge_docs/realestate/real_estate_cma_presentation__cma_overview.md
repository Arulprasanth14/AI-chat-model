## CMA Overview

When conducting the CMA Presentation brief for a Real Estate client, the **CMA Overview** section covers the following key information.

Ask the client: What property is this CMA being prepared for? Give the property address and suburb.

Ask the client: What type of property is it? The available choices include: "House", "Apartment", "Townhouse", "Villa", "Land", "Commercial Property".

Ask the client: What is the purpose of this CMA? This is more useful than asking "What type of presentation is this?" — the asset is already a CMA. The available choices include: "Listing Appointment", "Vendor Meeting", "Property Valuation Discussion", "Market Update", "Pre-Sale Consultation".
