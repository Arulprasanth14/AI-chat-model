## Content Structure

When conducting the Email Template brief for a Real Estate client, the **Content Structure** section covers the following key information.

Ask the client: Which sections should be included in the template? The client may select one or more from: "Hero Banner", "Intro Section", "Featured Content", "Product Grid", "Offer Section", among others.

Ask the client: Do you already have content prepared? The available choices include: "Yes, final content ready", "Partial content available", "Need help organising content".

Ask the client: What copy or placeholder content should appear in the template? Provide approved content or indicate which sections should use editable placeholders.
