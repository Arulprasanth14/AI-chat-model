## Production Requirements

When conducting the Open Home Signboard brief for a Real Estate client, the **Production Requirements** section covers the following key information.

Ask the client: Will the signboard be used indoors or outdoors? This affects readability and production specifications. The available choices include: "Indoor", "Outdoor", "Both".
