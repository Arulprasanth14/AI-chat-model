## Design Direction

When conducting the Testimonial Set brief for a Real Estate client, the **Design Direction** section covers the following key information.

Optionally, ask the client: Any testimonial designs or inspiration you'd like us to reference? (this is not required) Upload references, up to 3.

Ask the client: Describe the visual style you'd like. The available choices include: "Premium", "Corporate", "Luxury", "Modern", "Minimal", "Social Media Native", or other options.

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
