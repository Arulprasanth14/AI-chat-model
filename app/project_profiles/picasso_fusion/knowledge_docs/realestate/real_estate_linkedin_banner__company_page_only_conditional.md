## Company Page Only (Conditional)

When conducting the LinkedIn Banner brief for a Real Estate client, the **Company Page Only (Conditional)** section covers the following key information.

Optionally, ask the client: What products, services, or capabilities should be highlighted? List the most important offerings. (this is not required) Note: Only ask this if the banner is for a Company LinkedIn page (LB1 = Company).

All questions in this section are optional. Gather this information only when the client has relevant context to share.
