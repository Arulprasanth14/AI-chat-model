## Closing & CTA

When conducting the CMA Presentation brief for a Real Estate client, the **Closing & CTA** section covers the following key information.

Ask the client: What should the presentation conclude with? The available choices include: "Recommended Price Range", "Suggested Marketing Strategy", "Listing Proposal", "Book Listing Appointment", "Contact Agent".

Ask the client: Will a QR code be included? The available choices include: "Yes", "No".

Optionally, ask the client: What should the QR code destination URL be? (this is not required) Note: Only ask this if the client said yes to including a QR code.

In this section, 2 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
