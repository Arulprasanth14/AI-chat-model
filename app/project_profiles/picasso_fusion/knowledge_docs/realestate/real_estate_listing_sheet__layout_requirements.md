## Layout Requirements

When conducting the Real Estate Listing Sheet brief for a Real Estate client, the **Layout Requirements** section covers the following key information.

Ask the client: What format should the listing sheet be? The available choices include: "A4 Single-sided", "A4 Double-sided", "US Letter", "Custom Size".

Ask the client: Approximately how many property images should be featured? This dramatically affects layout decisions. The available choices include: "1–3", "4–6", "7–10", "10+".
