## Personal Profile Only (Conditional)

When conducting the LinkedIn Banner brief for a Real Estate client, the **Personal Profile Only (Conditional)** section covers the following key information.

Optionally, ask the client: What do you want to be known for professionally? (this is not required) Note: Only ask this if the banner is for a Personal LinkedIn profile (LB1 = Personal). The available choices include: "Real Estate Advisor", "SaaS Founder", "Fractional CMO", "Executive Coach", "Business Consultant".

All questions in this section are optional. Gather this information only when the client has relevant context to share.
