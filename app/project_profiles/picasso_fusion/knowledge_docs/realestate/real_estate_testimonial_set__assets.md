## Assets

When conducting the Testimonial Set brief for a Real Estate client, the **Assets** section covers the following key information.

Ask the client: Do you have a photo of the featured client? Please upload it.

Ask the client: Do you have additional assets to include? The client may select one or more from: "Company logo", "Star rating", "Product screenshots", "Before/after images", "Brand imagery", among others.

Optionally, ask the client: Please upload the available assets you selected. (this is not required) Note: Only ask this if the client selected any asset other than "None" above.

In this section, 2 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
