## Presentation Structure

When conducting the CMA Presentation brief for a Real Estate client, the **Presentation Structure** section covers the following key information.

Ask the client: Approximately how many slides are required? The available choices include: "8–12 Slides", "12–15 Slides", "Custom".

Optionally, ask the client: Do you have an existing CMA template or previous presentation to follow? Please upload the existing files. (this is not required)

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
