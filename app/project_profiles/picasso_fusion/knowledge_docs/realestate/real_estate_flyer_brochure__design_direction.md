## Design Direction

When conducting the Property Flyer / Brochure brief for a Real Estate client, the **Design Direction** section covers the following key information.

Optionally, ask the client: Any reference property flyers or brochures to share? (this is not required) Examples from competitors, previous listings, luxury real estate brands, or styles you admire. Up to 3 references.

Ask the client: Describe the design style you'd like. The available choices include: "Luxury Real Estate", "Premium Residential", "Commercial Corporate", "Modern Minimal", "Editorial", "High-End Lifestyle".

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
