## Call to Action

When conducting the Email Template brief for a Real Estate client, the **Call to Action** section covers the following key information.

Ask the client: What CTA buttons should be available in the template? The client may select one or more from: "Learn More", "Shop Now", "Book a Demo", "Register", "Contact Us".

Ask the client: Will CTA links require UTM tracking? The available choices include: "Yes", "No".

Optionally, ask the client: Please provide the UTM parameters, or confirm you'd like AI-generated UTMs. (this is not required) Note: Only ask this if the client said yes to UTM tracking above.

In this section, 2 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
