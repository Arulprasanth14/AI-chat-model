## Production Requirements

When conducting the Property Flyer / Brochure brief for a Real Estate client, the **Production Requirements** section covers the following key information.

Ask the client: Will this be used for print, digital PDF distribution, or both? The available choices include: "Print only", "Digital PDF only", "Both".
