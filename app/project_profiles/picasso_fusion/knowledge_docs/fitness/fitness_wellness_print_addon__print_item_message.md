## Print Item & Message

When conducting the Print Design brief for a Fitness client, the **Print Item & Message** section covers the following key information.

Ask the client: What are we creating today? Select the print item. The available choices include: "Flyer", "Poster", "Brochure", "Bifold Brochure", "Trifold Brochure", "Catalogue", or other options.

Ask the client: What's the one message people should remember? Describe the main purpose of this print piece. Example: "Grand opening this Saturday.", "Introducing our new premium apartment project.", "Summer sale up to 50% off.".
