## Style & References

When conducting the Print Design brief for a Fitness client, the **Style & References** section covers the following key information.

Ask the client: What style should this print design have? Choose up to 3. The client may select one or more from: "Premium", "Luxury", "Modern", "Minimal", "Bold", among others.

Optionally, ask the client: Do you have any inspiration? (this is not required) Share examples you like. The client may select one or more from: "Upload Images", "Pinterest Link", "Website Link", "PDF Reference", "Skip".

Optionally, ask the client: Provide the reference link(s), or note that you're uploading files. (this is not required) Note: Only if you selected a reference option above (not Skip).

In this section, 1 question(s) are required and 2 are optional — follow up on optional items only when contextually appropriate.
