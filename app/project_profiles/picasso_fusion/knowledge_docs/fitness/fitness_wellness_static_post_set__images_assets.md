## Images & Assets

When conducting the Static Post Set brief for a Fitness client, the **Images & Assets** section covers the following key information.

Ask the client: Do you have photos to use? The client may select one or more from: "Student Photo", "Faculty Photo", "Classroom Photo", "Campus Photo", "Event Photo", among others.

Optionally, ask the client: Upload your images. (this is not required) Recommended: 1080 × 1080 px or higher, PNG or JPG. Only if you selected "I'll Upload Custom Images" above.

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
