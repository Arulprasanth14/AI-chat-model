## Post Topic & Message

When conducting the Static Post Set brief for a Fitness client, the **Post Topic & Message** section covers the following key information.

Ask the client: What are we promoting? Choose one primary topic for this post. The available choices include: "Course / Program", "New Batch", "Student Result", "Student Testimonial", "Faculty Spotlight", "Free Workshop", or other options.

Ask the client: What's the one message you want people to remember? Describe the main takeaway. Examples: "Admissions open for our NEET crash course.", "127 students scored above 95%.", "Free career guidance seminar this Saturday.".

Ask the client: Which course, class, result or service is being featured? Provide the Course/Program Name, Key Benefit, and who it's for. Example: Course: JEE Advanced Foundation Program; Benefit: Improve problem-solving and rank potential; Audience: Class 11 & 12 students.
