## Carousel Topic & Message

When conducting the Carousel Set brief for a Fitness client, the **Carousel Topic & Message** section covers the following key information.

Ask the client: What is this carousel about? Choose the purpose. The available choices include: "Workout Guide", "Exercise Technique", "Fitness Tips", "Nutrition Advice", "Transformation Story", "Client Success Story", or other options.

Ask the client: What's the ONE message people should remember? Example: "Progress beats perfection.", "5 mistakes preventing fat loss.", "Our 12-week transformation program is now open.".
