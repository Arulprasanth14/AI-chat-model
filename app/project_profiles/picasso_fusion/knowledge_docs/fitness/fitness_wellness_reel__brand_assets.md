## Brand Assets

When conducting the Reel brief for a Fitness client, the **Brand Assets** section covers the following key information.

Ask the client: Would you like us to follow your existing brand identity? Brand Assets & Guidelines. The available choices include: "Use My Saved Brand Kit", "Upload Brand Guidelines", "Upload Logo & Assets", "Customize This Project".

Optionally, ask the client: What should we customize? (this is not required) Note: Only if you selected "Customize This Project" above. The client may select one or more from: "Brand Colors", "Brand Fonts", "Logo Placement", "Additional Instructions".

Optionally, ask the client: Provide any additional brand customization details. (this is not required) Note: Only if you selected "Customize This Project" above.

In this section, 1 question(s) are required and 2 are optional — follow up on optional items only when contextually appropriate.
