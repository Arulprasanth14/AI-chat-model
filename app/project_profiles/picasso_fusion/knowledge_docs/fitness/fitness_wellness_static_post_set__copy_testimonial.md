## Copy & Testimonial

When conducting the Static Post Set brief for a Fitness client, the **Copy & Testimonial** section covers the following key information.

Ask the client: Do you already have the copy? The available choices include: "Final Copy Ready", "Rough Points Only", "Need Copywriting Support".

Optionally, ask the client: Provide your copy or rough points. (this is not required) Note: Only if you have final copy or rough points ready.

Ask the client: Are you featuring a student review or testimonial? The available choices include: "Yes", "No".

Optionally, ask the client: Provide the student name, course name, and testimonial text. (this is not required) Note: Only if you are featuring a student review or testimonial.

Optionally, ask the client: Has permission been obtained to use this testimonial? (this is not required) Note: Only if you are featuring a student review or testimonial. The available choices include: "Yes", "No".

In this section, 2 question(s) are required and 3 are optional — follow up on optional items only when contextually appropriate.
