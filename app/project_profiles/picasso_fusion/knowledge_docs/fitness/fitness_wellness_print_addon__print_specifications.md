## Print Specifications

When conducting the Print Design brief for a Fitness client, the **Print Specifications** section covers the following key information.

Ask the client: What print size do you need? The available choices include: "Standard Size", "Custom Size".

Optionally, ask the client: Provide the width, height, and unit. (this is not required) Note: Only if you selected Custom Size above.

Ask the client: What orientation should the design be? The available choices include: "Portrait", "Landscape", "Square".

Ask the client: Single-sided or double-sided printing? The available choices include: "Single-Sided", "Double-Sided".

Optionally, ask the client: Any additional print specifications? (this is not required) Examples: Number of pages (for brochures, catalogues, booklets), Fold type (Bi-fold, Tri-fold, Z-fold, Gate fold), bleed/dieline supplied, printer specifications available. Leave blank if not applicable.

Optionally, ask the client: Upload your bleed/dieline or printer specifications. (this is not required) Note: Only if you have these available.

In this section, 3 question(s) are required and 3 are optional — follow up on optional items only when contextually appropriate.
