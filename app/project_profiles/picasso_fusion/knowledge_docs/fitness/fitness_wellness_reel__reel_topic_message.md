## Reel Topic & Message

When conducting the Reel brief for a Fitness client, the **Reel Topic & Message** section covers the following key information.

Ask the client: What is this Reel about? Choose the purpose. The available choices include: "Workout Demonstration", "Exercise Tutorial", "Client Transformation", "Fitness Tips", "Nutrition Advice", "Gym Promotion", or other options.

Ask the client: What's the ONE message viewers should remember? Describe the biggest takeaway. Example: "Strength training is for everyone.", "Join our 8-week fat loss challenge.", "Small daily habits create lasting results.".
