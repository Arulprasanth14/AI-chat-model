## Goal & Offer

When conducting the Static Post Set brief for a Fitness client, the **Goal & Offer** section covers the following key information.

Ask the client: What's the goal of this post? What action should people take?. The available choices include: "Call Us", "WhatsApp Us", "Visit Website", "Enquire Now", "Register for Event", "Book Free Consultation", or other options.

Optionally, ask the client: Is there an offer, announcement or important detail? (this is not required) Include any dates, discounts, deadlines, limited seats, scholarship details, or special benefits.

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
