## Script

When conducting the Reel brief for a Fitness client, the **Script** section covers the following key information.

Ask the client: Do you already have a script or talking points? The available choices include: "Final Script Ready", "Rough Ideas", "Need Scriptwriting Support", "No Voiceover Required".

Optionally, ask the client: Provide your script or rough talking points. (this is not required) Note: Only if you selected "Final Script Ready" or "Rough Ideas" above.

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
