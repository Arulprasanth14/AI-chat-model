## Goal & Audience

When conducting the Carousel Set brief for a Fitness client, the **Goal & Audience** section covers the following key information.

Ask the client: What's the goal of this carousel? The client may select one or more from: "Get More Enquiries", "Sell a Program", "Promote Personal Training", "Educate Followers", "Build Trust", among others.

Ask the client: Who is this for? Example: Beginners, Weight loss clients, Women, Men, Athletes, Busy professionals, Seniors, Everyone. The client may select one or more from: "Beginners", "Weight Loss Clients", "Women", "Men", "Athletes", among others.
