## Publishing & Language

When conducting the Carousel Set brief for a Fitness client, the **Publishing & Language** section covers the following key information.

Ask the client: Where will this carousel be published? The available choices include: "Instagram (1:1)", "Instagram (4:5)", "Facebook", "LinkedIn PDF", "Custom".

Ask the client: What language should we use? The available choices include: "English", "Hindi", "Tamil", "Telugu", "Malayalam", "Kannada".
