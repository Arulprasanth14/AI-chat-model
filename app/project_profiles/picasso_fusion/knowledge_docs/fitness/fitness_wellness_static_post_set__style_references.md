## Style & References

When conducting the Static Post Set brief for a Fitness client, the **Style & References** section covers the following key information.

Ask the client: What visual style should this post have? Choose up to 3. The client may select one or more from: "Premium", "Academic", "Professional", "Modern", "Minimal", among others.

Optionally, ask the client: Do you have any reference designs? (this is not required) The client may select one or more from: "Upload Images", "Instagram Link", "Website Link", "Pinterest Link", "Skip".

Optionally, ask the client: Provide the reference link(s), or upload the images. (this is not required) Note: Only if you selected a reference option above (not Skip).

In this section, 1 question(s) are required and 2 are optional — follow up on optional items only when contextually appropriate.
