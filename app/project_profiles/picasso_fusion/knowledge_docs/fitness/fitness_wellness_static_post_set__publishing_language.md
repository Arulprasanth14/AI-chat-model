## Publishing & Language

When conducting the Static Post Set brief for a Fitness client, the **Publishing & Language** section covers the following key information.

Ask the client: Where will this post be published? The client may select one or more from: "Instagram Feed", "Instagram Story", "Facebook", "LinkedIn", "WhatsApp", among others.

Ask the client: What language should this post use? The available choices include: "English", "Hindi", "Tamil", "Telugu", "Malayalam", "Kannada".
