## Style & References

When conducting the Video brief for a Fitness client, the **Style & References** section covers the following key information.

Optionally, ask the client: Do you have any inspiration? (this is not required) Share videos you like. The client may select one or more from: "YouTube Link", "Vimeo Link", "Instagram Reel", "TikTok", "Upload Reference Video", among others.

Optionally, ask the client: Provide the reference link(s). (this is not required) Note: Only if you selected YouTube Link, Vimeo Link, Instagram Reel, or TikTok above.

Optionally, ask the client: Upload reference video. (this is not required) Note: Only if you selected "Upload Reference Video" above.

All questions in this section are optional. Gather this information only when the client has relevant context to share.
