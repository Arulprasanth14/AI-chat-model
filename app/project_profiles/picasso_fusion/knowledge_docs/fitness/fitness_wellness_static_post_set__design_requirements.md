## Design Requirements

When conducting the Static Post Set brief for a Fitness client, the **Design Requirements** section covers the following key information.

Optionally, ask the client: Is there anything that must appear on the design? (this is not required) Select all that apply. The client may select one or more from: "Logo", "Phone Number", "WhatsApp Number", "Website", "QR Code", among others.

Ask the client: What should appear as the main headline? This is the biggest text on the design. Examples: "Admissions Open", "AIR 23 in JEE Advanced", "Free Career Guidance Seminar".

In this section, 1 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
