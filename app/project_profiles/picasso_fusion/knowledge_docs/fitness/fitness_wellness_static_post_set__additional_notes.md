## Additional Notes

When conducting the Static Post Set brief for a Fitness client, the **Additional Notes** section covers the following key information.

Optionally, ask the client: Is there anything you'd like us to avoid? (this is not required) Examples: "Avoid overly corporate visuals.", "Don't use stock student photos.", "Keep the design premium and clean.".

All questions in this section are optional. Gather this information only when the client has relevant context to share.
