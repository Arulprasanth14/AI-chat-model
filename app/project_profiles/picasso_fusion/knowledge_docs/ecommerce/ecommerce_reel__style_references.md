## Style & References

When conducting the Reel brief for a Ecommerce client, the **Style & References** section covers the following key information.

Optionally, ask the client: Do you have any inspiration? (this is not required) Share Reels or videos you like. The client may select one or more from: "Instagram Reel", "TikTok", "YouTube Shorts", "Upload Reference Video", "Skip".

Optionally, ask the client: Provide the reference link(s). (this is not required) Note: Only if you selected Instagram Reel, TikTok, or YouTube Shorts above.

Optionally, ask the client: Upload reference video. (this is not required) Note: Only if you selected "Upload Reference Video" above.

All questions in this section are optional. Gather this information only when the client has relevant context to share.
