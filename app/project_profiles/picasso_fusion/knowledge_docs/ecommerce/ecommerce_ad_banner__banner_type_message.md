## Banner Type & Message

When conducting the Ad Banner brief for a Ecommerce client, the **Banner Type & Message** section covers the following key information.

Ask the client: What are we creating today? Select the banner type. The available choices include: "Meta Ad Banner", "Google Display Banner", "Website Promotional Banner", "Homepage Hero Banner", "Retargeting Banner", "Seasonal Campaign Banner", or other options.

Ask the client: What are we promoting? Provide the key product or service information: Product/Service Name, Category, Price (Optional), Key Features/Benefits.

Ask the client: What's the ONE message customers should remember? Describe the biggest reason someone should click. Example: "Save up to 50% this weekend.", "Premium skincare made for sensitive skin.", "Free shipping on all orders.".
