## Post Purpose & Product

When conducting the Static Post brief for a Ecommerce client, the **Post Purpose & Product** section covers the following key information.

Ask the client: What are we creating today? Select the purpose of this post. The available choices include: "Product Launch", "Product Promotion", "New Arrival", "Best Seller", "Limited-Time Offer", "Seasonal Campaign", or other options.

Ask the client: Which product are we featuring? Provide the key product details: Product Name, Category, Price (Optional), Key Benefits/Features, Available Colours, Sizes or Variants (Optional).

Ask the client: What's the one message customers should remember? Describe the biggest reason someone should buy this product. Example: "Ultra-light running shoes designed for all-day comfort.", "Organic skincare made for sensitive skin.".
