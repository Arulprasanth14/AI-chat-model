## Placement & Sizes

When conducting the Ad Banner brief for a Ecommerce client, the **Placement & Sizes** section covers the following key information.

Ask the client: Where will this banner be used? The client may select one or more from: "Meta (Facebook & Instagram)", "Google Display Network", "LinkedIn", "Website", "YouTube Display", among others.

Ask the client: What banner sizes do you need? The available choices include: "Use Recommended Platform Sizes", "Single Size", "Multiple Sizes", "Custom Dimensions".

Optionally, ask the client: Provide the width × height in pixels. (this is not required) Note: Only if you selected Custom Dimensions above.

In this section, 2 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
