## Mockup Type & Product

When conducting the Product Mockup brief for a Ecommerce client, the **Mockup Type & Product** section covers the following key information.

Ask the client: What are we creating today? Select the type of mockup. The available choices include: "Product Mockup", "Packaging Mockup", "Bottle Mockup", "Jar / Tube Mockup", "Box Mockup", "Apparel Mockup", or other options.

Ask the client: Which product(s) are we showcasing? Provide the key product information: Product Name, Category, Colours/Variants, Size or Dimensions (Optional), Key Features.

Ask the client: What's the ONE message customers should remember? Describe the impression this mockup should create. Example: "Premium skincare with a luxurious feel.", "Minimal, sustainable packaging.", "Designed for modern professionals.".
