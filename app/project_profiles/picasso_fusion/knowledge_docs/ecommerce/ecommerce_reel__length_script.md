## Length & Script

When conducting the Reel brief for a Ecommerce client, the **Length & Script** section covers the following key information.

Ask the client: How long should the Reel be? The available choices include: "Under 15 Seconds", "15–30 Seconds", "30–60 Seconds", "Let the Creative Team Decide".

Ask the client: Do you already have a script or talking points? The available choices include: "Final Script Ready", "Rough Ideas", "Need Copywriting Support", "No Voiceover Required".

Optionally, ask the client: Provide your script or rough talking points. (this is not required) Note: Only if you selected "Final Script Ready" or "Rough Ideas" above.

In this section, 2 question(s) are required and 1 are optional — follow up on optional items only when contextually appropriate.
