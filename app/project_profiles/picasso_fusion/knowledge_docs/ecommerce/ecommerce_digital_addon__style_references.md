## Style & References

When conducting the Digital Asset brief for a Ecommerce client, the **Style & References** section covers the following key information.

Ask the client: What visual style should this asset have? Choose up to 3. The client may select one or more from: "Premium", "Luxury", "Modern", "Minimal", "Retail", among others.

Optionally, ask the client: Do you have any inspiration? (this is not required) Share examples you like. The client may select one or more from: "Website Link", "Instagram Link", "Pinterest Link", "Upload Images", "Skip".

Optionally, ask the client: Provide the reference link(s), or note that you're uploading images. (this is not required) Note: Only if you selected a reference option above (not Skip).

In this section, 1 question(s) are required and 2 are optional — follow up on optional items only when contextually appropriate.
