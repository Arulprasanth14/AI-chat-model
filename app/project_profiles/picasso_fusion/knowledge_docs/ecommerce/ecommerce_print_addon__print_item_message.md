## Print Item & Message

When conducting the Print Design brief for a Ecommerce client, the **Print Item & Message** section covers the following key information.

Ask the client: What are we creating today? Select the print item. The available choices include: "Flyer", "Poster", "Brochure", "Product Catalogue", "Shelf Talker / Shelf Wobbler", "Price Card / Product Tag", or other options.

Ask the client: Which product(s) are we promoting? Provide the key product information: Product Name(s), Category, Price (Optional), Key Features/Benefits, Colours/Sizes/Variants (Optional).

Ask the client: What's the ONE message customers should remember? Describe the biggest reason someone should buy. Example: "Premium quality at an everyday price.", "Designed for all-day comfort.", "Limited-time festive collection.".
