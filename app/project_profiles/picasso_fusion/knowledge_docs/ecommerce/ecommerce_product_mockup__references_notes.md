## References & Notes

When conducting the Product Mockup brief for a Ecommerce client, the **References & Notes** section covers the following key information.

Optionally, ask the client: Do you have any inspiration? (this is not required) Share mockups or product visuals you like. The client may select one or more from: "Website Link", "Pinterest Link", "Instagram Link", "Upload Images", "Skip".

Optionally, ask the client: Provide the reference link(s), or note that you're uploading images. (this is not required) Note: Only if you selected a reference option above (not Skip).

Optionally, ask the client: Is there anything you'd like us to avoid? (this is not required) Mention any colours, props, backgrounds, compositions, or visual styles you'd prefer not to use.

All questions in this section are optional. Gather this information only when the client has relevant context to share.
