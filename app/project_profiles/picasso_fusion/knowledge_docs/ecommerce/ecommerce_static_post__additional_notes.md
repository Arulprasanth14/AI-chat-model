## Additional Notes

When conducting the Static Post brief for a Ecommerce client, the **Additional Notes** section covers the following key information.

Optionally, ask the client: Is there anything you'd like us to avoid? (this is not required) Mention any colours, imagery, wording, styles, or competitor references you'd prefer not to use.

All questions in this section are optional. Gather this information only when the client has relevant context to share.
